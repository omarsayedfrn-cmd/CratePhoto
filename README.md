# دليل هيكل مشروع مصمم الصور 🎨

تمت إعادة هيكلة وتقسيم المشروع بالكامل ليصبح نظيفاً، سريعاً، وسهل التعديل والتطوير، مع المحافظة التامة على كافة الميزات والبيانات السابقة.

---

## 📁 هيكلية المجلدات والملفات

```text
PotoTool/
├── index.html                 # الملف الرئيسي (نظيف وسهل القراءة)
├── مصمم-الصور-v3.html          # نسخة متطابقة مع index.html لسهولة الفتح
├── مصمم-الصور-مستقل.html       # نسخة مدمجة شاملة تعمل كملف منفرد دون مجلدات
├── مصمم-الصور-v3.html.backup  # النسخة الاحتياطية من الملف الأصلي القديم
│
├── css/
│   ├── style.css             # تنسيقات الواجهة والألوان والوضع الليلي (مرتب ومقسم)
│   └── fonts.css             # خطوط Base64 المدمجة (فُصلت لتجنب تجميد محرر الأكواد)
│
└── js/
    ├── canvas-utils.js       # دوال الرسم الأساسية (نصوص، ظلال، أشكال، خلفيات، إطارات)
    ├── templates.js          # دوال رسم القوالب التسعة (غلاف، فقاعة، شمس، قطري، بطاقات...)
    └── app.js                # المنطق الرئيسي (إدارة الشرائح، التخزين، رفع الصور، التصدير)
```

## 🛠️ كيف تعدل على المشروع بسهولة؟

1. **تعديل النصوص أو عناصر الواجهة:**
   - افتح [index.html](file:///home/omsa/Downloads/مواقع/PotoTool/index.html) أو [مصمم-الصور-v3.html](file:///home/omsa/Downloads/مواقع/PotoTool/مصمم-الصور-v3.html).

3. **تعديل شكل أي قالب أو إضافة قالب جديد:**
   - افتح [js/templates.js](file:///home/omsa/Downloads/مواقع/PotoTool/js/templates.js).
   - كل قالب مكتوب بدالة واضحة ومنفصلة مع توثيق كامل لجميع المعاملات.

4. **تعديل الخطوط والظلال أو دوال الكانفاس:**
   - افتح [js/canvas-utils.js](file:///home/omsa/Downloads/مواقع/PotoTool/js/canvas-utils.js).

5. **تعديل المنطق أو التحميل أو الحفظ:**
   - افتح [js/app.js](file:///home/omsa/Downloads/مواقع/PotoTool/js/app.js).

## 🚀 النشر على Vercel (للاستخدام الشخصي)

المشروع موقع ثابت (Static) بدون خطوة بناء، فأي طريقة من الطرق دي تشتغل:

### الطريقة الأولى: لوحة تحكم Vercel (الأسهل)
1. اعمل حساب على [vercel.com](https://vercel.com).
2. من Dashboard اختر **Add New → Project**.
3. اسحب فولدر المشروع أو اربطه بمستودع GitHub.
4. الإعدادات:
   - **Framework Preset:** Other
   - **Build Command:** (اتركه فاضي)
   - **Output Directory:** (اتركه فاضي — الجذر هو أصل الموقع)
5. اضغط **Deploy**.

### الطريقة الثانية: عبر Vercel CLI
```bash
npm i -g vercel      # تثبيت مرة واحدة
cd PotoTool          # فولدر المشروع
vercel               # نشر تجريبي (Preview)
vercel --prod        # النشر الرسمي
```

### ملاحظات مهمة
- الصفحة الرئيسية هي [index.html](file:///home/omsa/Downloads/مواقع/PotoTool/index.html) وتُفتح على الجذر `/` مباشرة.
- ملف [vercel.json](file:///home/omsa/Downloads/مواقع/PotoTool/vercel.json) بيضبط الروابط النظيفة وهيدرات الأمان والتخزين المؤقت.
- ملف [.vercelignore](file:///home/omsa/Downloads/مواقع/PotoTool/.vercelignore) بيستبعد النسخة الاحتياطية `*.backup` من الرفع.
- الموقع ممنوع من الأرشفة عبر [robots.txt](file:///home/omsa/Downloads/مواقع/PotoTool/robots.txt) و`noindex` لأنه للاستخدام الشخصي.
- كل البيانات (الشرائح + قوالب الستايل + إعدادات الشبكة) بتتخزن في متصفح المستخدم (localStorage)، يعني مفيش سيرفر ولا قاعدة بيانات.
